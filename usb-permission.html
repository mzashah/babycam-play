Skip the “Start now” prompt

Optional · for parents with a computer · BabyCam (com.mzashah.babycam) · Last updated: 25 November 2026

When a parent asks to see the baby phone’s screen, Android shows its own “Start recording or casting?” → Start now prompt on the baby phone. Android requires this for every app, and BabyCam shows it automatically.

If you have a computer, you can give BabyCam a one-time permission so Android stops asking on that phone. It is optional — BabyCam works fully without it.

Good to know. This works on some phones. Others, especially Android 14 and newer, may still ask. If the prompt keeps appearing after these steps, simply tap Start now as before — nothing is broken. Use it only on a phone you own or a child’s phone you are responsible for.

What you need

  • The baby phone (the phone being viewed), with BabyCam installed.
  • A computer (Windows, Mac or Linux) and a USB cable.
  • About 5 minutes.

Steps

  1. Install ADB on the computer. It is Google’s free “platform-tools” package: download it, unzip it, and open a terminal / command prompt in that folder. On a Mac you can also run brew install android-platform-tools.
  2. Turn on USB debugging on the baby phone. Settings › About phone › tap Build number 7 times › back to Settings › Developer options › turn on USB debugging.
    • Oppo, Realme, OnePlus: also turn on Disable permission monitoring in Developer options.
    • Xiaomi, Redmi, POCO: also turn on USB debugging (Security settings) (it may ask you to sign in to a Mi account).
  3. Connect the phone to the computer with the USB cable. On the phone, tap Allow on “Allow USB debugging?”. In the terminal, run adb devices — your phone should be listed as device.
  4. Run this command in the terminal: 
    adb shell appops set com.mzashah.babycam PROJECT_MEDIA allow
    It prints nothing when it works.
  5. Check it. On the baby phone open BabyCam › Settings › Parent control › Skip “Start now” (advanced) — the status should say Active. You can also run 
    adb shell appops get com.mzashah.babycam PROJECT_MEDIA
    (it should say allow).
  6. Clean up (recommended). Turn USB debugging off again on the baby phone and unplug the cable.

Good to know

QuestionAnswer
Does it show less to the child?No. Screen viewing still needs the parent to turn it on in Parent control, and the baby phone still shows the “A parent can view this screen” notification. Only Android’s confirmation prompt is skipped.
Is it safe?It is a standard Android permission you grant to the app yourself. It does not give BabyCam any new access to your data, and BabyCam never uploads the screen to any server.
When does it stop working?Reinstalling BabyCam or a factory reset removes it. Run the command again.
The command says “does not have MANAGE_APP_OPS_MODES”Your phone blocks it. Turn on the extra switch for your brand in step 2 (Oppo / Realme / OnePlus: Disable permission monitoring; Xiaomi / Redmi / POCO: USB debugging (Security settings)) and try again.

Undo it

adb shell appops set com.mzashah.babycam PROJECT_MEDIA default
