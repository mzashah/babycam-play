# BabyCam

Public Play Store home for the **BabyCam** Android app — landing page and privacy policy.
No app source code lives here (the source is a separate private repo).

- Website: https://mzashah.github.io/babycam-play/
- Privacy policy: https://mzashah.github.io/babycam-play/privacy.html

## Branches

- `develop` — work in progress: make and review all website changes here, then merge to `main` (owner approval) to publish.
